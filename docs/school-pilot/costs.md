# 構成・費用比較（購入/契約しない）

追記：本表の購入費用・按分試算は維持するが、学校に余剰機材がないため購入を最優先にはしない。
無料/学生credit、KVMレンタル、rootless/runsc、microVM、直接cloud VMの月額は
[追加比較](isolation-cloud-comparison.md)を参照する。

## 見積りの読み方

2026年11月18日に公式資料を参照した。以下のA/B/C金額は**予算比較用の仮定**で、
販売価格・取得済み見積り・為替相場・学校が支払う実費ではない。
CPU性能、実効容量、学校契約、税、地域、保守、電力を調達前に再確認する。
同じ32/64GiBでもCPU・SSD・冗長性が違うため、RAM価格だけでは比較しない。
クラウド契約・決済画面の操作や試用登録は行っていない。

公式価格の参考点（特定サービスの採用を推奨・決定するものではない）：

- [さくらVPS料金表](https://vps.sakura.ad.jp/specification/)の掲載例は月払い4GB/仮想4coreで3,520円、
  8GB/仮想6coreで7,040円。年額換算・地域差と混同しない。今回のWeb/API用2〜4 vCPU/4〜8GiBと
  同一商品条件ではなく、実行VMホストの候補でもない。転送/追加disk/backup等は別確認。
- [Hetzner AX42仕様](https://www.hetzner.com/dedicated-rootserver/ax42/)の掲載構成は64GB、
  2×512GB NVMe、1Gbit/s。メモリが足りてもdiskは今回の40環境計画に不足する。
  月額は取得ページに数値が表示されなかったため引用せず、必要容量の個別見積りを取得する段階で比較する。
  国外保存、遅延、学校の委託/越境方針も確認が必要。
- [Backblaze B2料金](https://www.backblaze.com/cloud-storage/pricing)の掲載開始価格は
  $6.95/TB/月、保存量のbyte-hour課金。転送無料条件や為替・税等は契約前に再確認する。
  backup3040GiBを十進TBへ換算すると約3.264TB、保存のみ約$22.69/月。
  **仮定**150円/USDなら約3,400円/月。4TiBを全量使えば約$30.57/月（同じ仮定で約4,600円）。
  この為替は現行レートではない。学校の承認なしに生徒データを外部へ保存しない。

## 学校所有/購入ホストを使うA/B/C予算例

月730時間ではなく、比較を揃えるため30日×24時間=720時間で計算する。
稼働VMが4でも停止環境のdiskを保持する。夜間停止でデータが消えたり、
専用ホストの月額料金が自動的に安くなったりするとは仮定しない。

| 仮定項目 | A：32GiB×1 | B：64GiB×1 | C：64GiB×2、初期全体4枠 |
| --- | ---: | ---: | ---: |
| Web/API+DB/Git用サービス予算/月 | 4,000円 | 7,000円 | 7,000円 |
| gateway/分離管理系の計算資源予算/月 | 2,000円 | 4,000円 | 6,000円 |
| VMホスト購入予算（実効2TiB込み） | 150,000円 | 250,000円 | 500,000円 |
| 同購入額の36ヶ月按分/月、端数切上げ | 4,167円 | 6,945円 | 13,889円 |
| VMホスト平均消費電力の仮定 | 90W | 130W | 合計260W |
| 電気31円/kWhという仮定で月額切上げ | 2,009円 | 2,902円 | 5,804円 |
| 外部backup媒体：4TiB×2組で計40,000円の36ヶ月按分/月 | 1,112円 | 1,112円 | 1,112円 |
| ネットワーク/UPS交換/部品等の予備予算/月 | 2,000円 | 3,000円 | 5,000円 |
| **資源費+按分合計/月** | **15,288円** | **24,959円** | **38,805円** |
| 運用工数の仮定（2,500円/時） | 4時間=10,000円 | 6時間=15,000円 | 12時間=30,000円 |
| **工数込み比較/月** | **25,288円** | **39,959円** | **68,805円** |
| ホスト+backupの初期資金（按分とは別のcash） | 190,000円 | 290,000円 | 540,000円 |

gateway/管理系予算には分離した管理用計算環境を含む想定。実行VMとの同居や
gatewayへの管理鍵配置でこの費用を削らない。ネットワーク/UPS予備費も実際の導入価格を保証しない。
電気はVMホスト分だけを明示計算し、管理系/backup機器の電力は各予算/予備費で別精算する。
教員の無償作業や学校の電気もコスト0と扱わない。
時給・工数は比較用であり、初期構築/障害対応/授業支援が月4時間に収まる保証はない。
設置工事・回線新設・組織の承認工数・税額差・予想外の故障/増設は別見積り。
Firebase/メール配信、監視サービス、DNS/TLS運用等の従量費も利用方式確定後に追加する。
無料枠で必ず賄えるとは仮定せず、今回の合計はこれら未確定費用を除く比較予算である。

初版で比較した専用ホストの再利用は、余剰機材なしという現在の条件では採用しない。
将来機材を入手しても電力/保守/backup/管理者の費用は残る。
稼働中の既存PCやDocker Desktopの転用は今回の選択肢にしない。
外部オブジェクトbackupへ置き換えるなら、媒体按分とクラウド費用を重複計上しないよう
保存世代/別障害領域を再設計する。学校側鍵管理・送受信・復元費用も含める。

## レンタル専用物理サーバーと比較する際の式

VMホスト購入按分＋VMホスト電力＋ホスト保守部分を、
「専用物理月額＋初期費用/36＋必要SSD/冗長化＋転送/IPv4＋学校との閉域接続」へ置き換える。
他のWeb/API、gateway、backup、運用費は残る。停止中diskの保存費を除外しない。
通常VPSの料金へVM4台分を足すだけの試算はせず、KVM/仮想化の契約上の可否と実機条件を確認する。

国外の安価なホストはレイテンシ、調達通貨、支払い、保守窓口、学校の個人情報方針で不適合になり得る。
価格が安いだけで採用しない。円換算は実見積り日・通貨・税・契約期間を明記して承認する。

## 低コスト化の優先順位

1. 40人が常用するWeb/APIをVM系と分離し、VMを使わない生徒の負荷は小型アプリ資源で受ける。
2. 本人環境を初回利用時に作り、最初は合成データ1〜2環境だけで安全性を試す。
   ただし全員利用後の40環境分の保存予算を先に計画する。
3. 全体4枠と授業時間割を維持。30分×40人÷4枠なら単純計算5時間かかるため、
   1授業で全員が同時に編集できるという期待を持たせない。
4. RAM64GiBは測定で必要なら採る。AのCPU/RAMが合格しない場合はBへ変更する比較を承認する。
   価格優先でゲスト隔離やbackupを削らない。
5. Cは運用経験・専用権威台帳・fencing・予算が整ってから。台数を増やしても初期枠は4のまま。
   将来10/20台ではホスト台数に比例する資源費に加え、管理/復旧工数とdisk複製・帯域費が増える。

未確定事項：学校所有機材、実CPU性能、利用可能回線/電力、許可保存国、教員当番、
1人のProject数、実Git容量、OS更新差分、backup期間と復元時間。
これらが埋まるまで購入・契約・実行機能有効化を行わない。
